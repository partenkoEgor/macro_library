# macro_library

Библиотека VBA-макросов для Excel (мониторинг поддержки: статусы тикетов, TTR/FTT, эффективность сотрудников).

Код лежит в `macros/` как есть, без правок. Файлы в UTF-8. В репозитории строки заканчиваются на LF, при checkout Git подставляет CRLF (см. `.gitattributes`).

> **Импорт в Excel.** Редактор VBA (Alt+F11 → File → Import File) читает `.bas` в кодировке Windows-1251. Если кириллица в комментариях и строках превращается в кракозябры, конвертируйте файл перед импортом:
> `iconv -f UTF-8 -t CP1251 macros/X.bas > X_cp1251.bas`.
> Или создайте модуль вручную и вставьте код через буфер обмена.

## Каталог

| Файл | Точка входа | Что делает |
|---|---|---|
| `Monitoring_StatusChains.bas` | `Monitoring_Цепочек_Статусов` | По сводной таблице находит «Медианное время перехода» для 13 фиксированных статусов и строки «Общее». Собирает лист «Результат» (значения в формате `[h]:mm:ss`), копирует `B2:B17` в буфер. Ячейки с ненайденным статусом или некорректным временем подсвечивает красным. |
| `Monitoring_TTR_FTT.bas` | `Monitoring_TTR_FTT` | Берёт **второй** лист выгрузки (медианы) и строит лист «Упорядоченный список»: 39 стран в фиксированном порядке и значение метрики (`first_touch_hms_med`, `time_to_resolve_hms_med` или старая `med_dt_prev_diff_emp_sec_hms`). Названия стран нормализуются (регистр, тире, латиница вместо кириллицы). Добавляет кнопку «Копировать». |
| `Monitoring_EmployeeEfficiency.bas` | `Monitoring_Эффективность_Сотрудников` | Разворачивает выгрузку эффективности с листа `Sheet 1` в плоскую таблицу «Преобразованные»: Команда / Стол / Имя / дни 1–31. Дневная и ночная смены за одну дату суммируются. Строки `total` пропускаются. |
| `Monitoring_EmployeeSwitches.bas` | `Monitoring_Переключения_Сотрудников` | Аналог предыдущего для «переключений»: лист «Преобразованные данные», столбцы Стол / Имя / дни 1–31. Сумма по сотруднику за день считается по **всем** его столам и выводится в каждую его строку. Нулевой итог оставляется пустым. |
| `Monitoring_TicketMovements.bas` | `Monitoring_Перемещение_тикетов` | Из выгрузки «Начальный статус → Конечный статус» по дням строит лист «Маппинг_Цепочек»: 3 блока (Team B (BT M), Team A,B (API), Team A,B (PSP)) по 1..(вчера) дням месяца. Учитывается только блок «L2». У каждого блока своя кнопка «Копировать». Авторство в коде: «by Dilmurat». |

## Форматы исходных данных

Два макроса по сотрудникам читают лист `Sheet 1` с разной раскладкой, их нельзя менять местами:

| | `EmployeeEfficiency` | `EmployeeSwitches` |
|---|---|---|
| A | Команда | Стол |
| B | Стол | Имя |
| C | Имя | 1-е число, день |
| D… | 1-е число, день… | … |

В обоих случаях данные начинаются с 6-й строки, номер дня лежит в 4-й строке (в объединённых ячейках), тип смены («день»/«ночь») в 5-й.

## Зависимости и замечания

Замечания появились при первом чтении. Код я не менял.

1. **`CMB_CopyBlock` отсутствует.** Кнопка, которую создаёт `Monitoring_TTR_FTT`, вызывает `CMB_CopyBlock`, но его нет в этой пачке. Без него кнопка «Копировать» не сработает. Скорее всего, он лежит в следующей пачке.
2. **`fillSwitchData()` отсутствует.** `Monitoring_EmployeeSwitches` ссылается на «старый `fillSwitchData()`», который синхронизирует данные с этого листа. В репозитории его нет.
3. **`FixLatChars` в `Monitoring_TTR_FTT` объявлена как `Public`** и имеет общее имя. Если в проекте появится другая функция с таким именем, будет конфликт. Достаточно сделать её `Private` или переименовать.
4. **`Monitoring_TicketMovements` 1-го числа месяца.** Ширина сетки — `Day(Date) - 1`, то есть 0 столбцов. Лист получится пустым, а диапазон копирования в кнопках развернётся (`B:A`). Ошибки нет, но результат бесполезен. Также нет обработчика ошибок: при сбое `ScreenUpdating` остаётся выключенным.
5. **Комментарий про `B:AF` в `Monitoring_TicketMovements` устарел.** Реальный диапазон — `B..(MAX_DAYS+1)`.
6. **Пустая замена `Replace(s, "'", "'")`** в `NormalizeKey` и `CleanText` (`Monitoring_TicketMovements`) ничего не делает. Вероятно, изначально там был типографский апостроф `’`, и он потерялся при копировании. Если в данных встретится типографский апостроф, он не будет приведён к обычному.
7. **`Monitoring_EmployeeSwitches` без `Option Explicit`.** Остальные модули его используют.
8. **Жёстко зашитые значения.** Это листы `Sheet 1` и «Второй лист», списки статусов (`Monitoring_StatusChains` с ID вроде `189`, `236`), стран и цепочек. При изменении набора статусов или стран правьте массивы в коде.
9. **Все макросы пишут результат на свой лист.** `Упорядоченный список`, `Преобразованные`, `Преобразованные данные` и `Маппинг_Цепочек` удаляются и создаются заново. Лист `Результат` очищается целиком (`Cells.Clear`). Не храните на этих листах ничего своего.
